---
title: Installation
description: How to install dependencies and run the project locally.
---

## Requirements

- Node.js 20 or later
- A package manager: pnpm (recommended), npm, yarn or bun

## Install dependencies

```npm
npm install
```

## Start the dev server

```npm
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the app and [/docs](/docs) for the documentation.

## Build for production

```npm
npm run build
```
